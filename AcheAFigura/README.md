# Ache a Figura

Jogo Android de identificação visual, responsivo para celulares, tablets e
aparelhos Android Go.

## Como jogar

- Encontre entre as 20 fichas o emoticon mostrado no centro.
- Um acerto remove a ficha, exibe brilho e toca o som de TADA.
- Um erro toca o som de falha e muda a figura procurada.
- Ao terminar, o jogo mostra um troféu e toca uma fanfarra.
- **Reiniciar** começa uma nova rodada e alterna entre animais, letras/números e emoticons variados.
- A barra inferior tem **Fixar**, **Reiniciar** e **Parar/Continuar**.

## Executar

```shell
flutter run
```

Gerar APK:

```shell
flutter build apk --debug
```
