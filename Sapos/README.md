# Sapos

Jogo Flutter para **Android** e **Android Go** (celular e tablet): um sapo come moscas numa sopa, sapos maus tentam roubá-las e sapos bons expulsam os maus.

## Como jogar

1. Toque numa **mosca** — o sapo lança a língua e come.
2. Toque num **sapo mau** (roxo) — o sapo joga uma bomba que explode nele.
3. **Sapos bons** (azuis) aparecem sozinhos e expulsam os maus.
4. Novas moscas e sapos surgem continuamente.

## Sons

- Língua, engolir, zumbido de mosca
- Ribbit dos sapos maus
- Bomba / explosão
- Vitória dos sapos bons

## Rodar

```bash
flutter pub get
flutter run
```
