# Marcianos

Jogo Flutter para Android e Android Go (celular e tablet): um buggy com canhão laser percorre uma pista sinuosa enquanto marcianos tentam atacá-lo.

## Como jogar

- O buggy percorre a pista sozinho, da faixa de partida até a chegada.
- Toque nos marcianos para disparar o laser amarelo do canhão.
- Resistência: pequenos 1 tiro, médios 2, grandes 3.
- Se um marciano alcançar o buggy: estouro → fogo → cinzas, e outro buggy (cor aleatória) nasce na partida.
- Ao cruzar a chegada, aparece um troféu.

## Controles

- **Fixar / Liberar** — pin da tela
- **Reiniciar** — nova partida
- **Parar / Continuar** — pausa

## Executar

```bash
flutter pub get
flutter run
```

```bash
flutter test
```
