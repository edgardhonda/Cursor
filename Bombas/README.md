# Bombas!

Jogo Android em Flutter, responsivo para celulares, tablets e aparelhos
Android Go. A arte é desenhada em tempo real com contornos coloridos e sem
preenchimento.

## Como jogar

- Toque em um espaço livre para posicionar uma bomba.
- Toque novamente na bomba para acender o pavio de três segundos.
- Bombas junto de árvores ou casas provocam incêndio e deixam cinzas.
- Bombas sem alvo deixam um buraco.
- Os trabalhadores transformam árvores em casas após cinco segundos.
- Construção, explosão, fogo e queda têm efeitos sonoros sincronizados.
- Use **Fixar**, **Reiniciar** e **Parar/Continuar** na barra inferior.

## Executar

```shell
flutter run
```

APK de depuração:

```shell
flutter build apk --debug
```
