# Obstáculos

Jogo de progressão lateral: um explorador atravessa a floresta e resolve obstáculos com o recurso certo.

## Como jogar

1. O personagem caminha sozinho pela tela.
2. Ao chegar num obstáculo, para e aparece um popup com **3 opções** (1 correta).
3. Escolha certa → animação da solução e segue.
4. Escolha errada → tristeza + som de falha → popup de novo.
5. No fim do trecho → comemoração e rola para um novo trecho (2 a 4 obstáculos).

## Requisitos

- Android / Android Go, celular e tablet
- Sons: caminhar, falha, comemorar, destruir, subir, splash, whoosh, tick
