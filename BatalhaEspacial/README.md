# Batalha Espacial

Jogo Android (celular, tablet e Android Go) em Flutter.

## Como jogar

1. Toque em **Pronto!** para começar.
2. A nave voa em perspectiva 3D enquanto o terreno passa embaixo.
3. Um inimigo aparece à frente com um **número de força** acima dele (tamanho proporcional à força).
4. Você tem **5 segundos** para escolher entre **3 números** na parte inferior da tela.
5. Acertou → inimigo destruído e pontos somados.
6. Errou ou o tempo acabou → nave destruída.

## Executar

```bash
flutter pub get
flutter run
flutter test
```
